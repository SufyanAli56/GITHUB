# 🔍 GitHub Account Finder

A modern web application built with Next.js that allows users to search and explore GitHub accounts using GitHub SDK / REST APIs.

This project helps developers quickly find GitHub profiles, repositories, and public account details in a clean and fast interface.

---

## 🚀 Features

- 🔎 Search GitHub users by username  
- 👤 View public profile details (bio, followers, following)  
- 📦 List public repositories  
- ⚡ Fast rendering using Next.js App Router  
- 🔐 Secure API access using environment variables  
- 📱 Responsive UI  

---

## 🧠 Tech Stack

- **Framework:** Next.js  
- **Language:** TypeScript / JavaScript  
- **Styling:** CSS / Tailwind CSS (optional)  
- **API:** GitHub REST API / GitHub SDK  
- **Deployment:** Vercel
